# Три Линии

Мобильная лейн-стратегия. У каждого игрока трон и 3 линии. Пять героев стоят на линиях как вышки: бьют вражеских крипов автоатакой и способностями. Крипы идут волнами с обеих сторон. Качаешь свою волну на линии, пока она не убьёт всех вражеских героев там, — враг откатывается на позицию назад, твои герои встают на его место. Три отката — и путь к трону открыт.

Версия 0.1: бой против бота, 10 героев, прокачка героев и крипов за золото, авто-способности, три уровня сложности.

## Структура

```
src/
  data/config.ts     баланс: золото, волны, крипы, цены прокачки, позиции вышек
  data/heroes.ts     10 героев и их способности (прототипы из Доты в поле proto)
  sim/game.ts        правила боя, без привязки к экрану
  sim/bot.ts         противник
  sim/map.ts         геометрия трёх линий
  render/renderer.ts отрисовка поля (Canvas 2D)
  main.ts            экраны и управление
tools/simtest.ts     прогон матчей бот против бота для проверки баланса
tools/bundle.py      сборка в один HTML для быстрой проверки
```

Весь баланс — в `src/data/config.ts` и `src/data/heroes.ts`. После правок запусти `npm run sim`: он прогонит 20 матчей бот против бота и покажет, кто выиграл и сколько длился бой.

## Запуск на компьютере

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откроется адрес вида `http://192.168.x.x:5173` — его можно открыть и на телефоне в той же Wi-Fi сети.

## Android: APK без установки чего-либо (через GitHub)

Сборка идёт в облаке GitHub по файлу `.github/workflows/android.yml`. Нужен только браузер.

1. Зарегистрируйся на github.com и создай репозиторий: **New repository** → имя `tri-linii` → **Private** → **Create repository**.
2. На странице репозитория нажми **uploading an existing file**, перетащи в окно **всё содержимое** папки `tron` (не саму папку) и нажми **Commit changes**.
3. Проверь, что в репозитории есть папка `.github`. Скрытые папки иногда не перетаскиваются. Если её нет: **Add file → Create new file**, в имени файла напиши `.github/workflows/android.yml`, вставь содержимое этого файла из архива, **Commit changes**.
4. Открой вкладку **Actions**. Сборка запустится сама и займёт 5–8 минут (зелёная галочка — готово).
5. Открой репозиторий с телефона → **Releases** справа → последняя сборка → скачай файл `tri-linii-0.1.N.apk`.
6. Открой скачанный файл. Android попросит разрешить установку из этого источника (браузера или «Файлов») — разреши и установи.

Каждая новая загрузка файлов в репозиторий даёт новую сборку с номером на 1 больше. Её можно ставить поверх старой — прогресс сохранится.

Это тестовая (debug) сборка: для себя и друзей. Для Google Play нужна подписанная сборка `.aab` — см. ниже.

## Android: сборка на компьютере и выпуск в Google Play

Нужны Node.js 20+ и Android Studio.

```bash
npm install
npm run build
npx cap add android        # один раз
npm run android            # сборка + открыть проект в Android Studio
```

Перед публикацией:

1. Поменяй `appId` в `capacitor.config.ts` на свой (например `ru.твоёимя.trilinii`). После первой публикации сменить его нельзя.
2. Зафиксируй портретную ориентацию: в `android/app/src/main/AndroidManifest.xml` у тега `<activity>` добавь `android:screenOrientation="portrait"`.
3. Иконки и заставка уже лежат в `assets/`. Сгенерировать из них все размеры: `npx @capacitor/assets generate --android`.
4. В Android Studio: Build → Generate Signed App Bundle → создай ключ (храни файл ключа и пароль, без них не выпустить обновление) → получишь `.aab`.
5. Google Play Console (разовый взнос 25 $): создай приложение, загрузи `.aab`, заполни возрастной рейтинг, анкету о данных (игра сейчас ничего не собирает) и ссылку на политику конфиденциальности.

Альтернатива для России — RuStore: принимает тот же подписанный `.apk`/`.aab`, регистрация разработчика бесплатная.

## Сборка для App Store (iOS)

Нужен Mac с Xcode и аккаунт Apple Developer (99 $ в год).

```bash
npm run build
npx cap add ios            # один раз
npm run ios                # открыть проект в Xcode
```

В Xcode: выбери команду подписи (Signing & Capabilities), в General → Deployment Info оставь только Portrait, затем Product → Archive → Distribute App → App Store Connect.

## Игра с другом

В меню «Игра с другом»: один создаёт комнату и получает код из 4 символов, второй вводит код. Соединение — через PeerJS (WebRTC): общий сервер PeerJS только помогает телефонам найти друг друга, дальше они общаются напрямую. Хост считает бой и 10 раз в секунду отправляет гостю снимок состояния, гость отправляет хосту только свои действия.

Проверить сеть без телефонов можно в браузере: открой собранную игру в двух вкладках одного браузера (без PeerJS игра сама переключается на связь между вкладками).

## Что дальше

- **Онлайн PvP.** Логика боя в `sim/` не зависит от экрана, поэтому её можно запустить на сервере (Node.js + WebSocket): сервер считает бой, клиенты шлют только действия «применить способность», «прокачать героя», «усилить крипов». Перед этим заменить `Math.random` в симуляции на генератор с общим зерном.
- **Способности.** Сейчас у каждого героя одна активная способность. Следующий шаг — 2–3 способности и пассивка, выбор что качать при повышении уровня.
- **Прокачка между боями.** Опыт за матчи, открытие героев, таланты.
- **Графика и звук.** Сейчас герои — цветные круги с буквой. Под спрайты отрисовка вынесена в `render/renderer.ts`.
- **Шрифты офлайн.** Шрифты сейчас грузятся из Google Fonts; без интернета используются системные. Для релиза скачай их в `public/fonts`.
