# Arena of Defense — заметки для продолжения работы

Этот файл — «память проекта» для нового диалога с Claude (или любого разработчика).
Здесь то, чего не видно из кода сразу: решения, причины, цифры, где что лежит.
Обновлено: 3 октября 2026, версия 0.1.28.

## Что это

Мобильная лейн-стратегия для Android (позже — магазины приложений). Карта в духе MOBA (как Mobile Legends):
два трона в противоположных углах, 3 линии (верх / центр / низ), по 3 позиции вышек на сторону на каждой линии.
Каждый игрок выбирает 5 героев (драфт по очереди, без повторов) и расставляет по линиям.
Герои — неподвижные «вышки» с HP, маной, автоатакой и способностью. Крипы идут волнами.
Если все герои стороны на линии пали — эта сторона откатывается на позицию назад. 3 отката — трон открыт, снести трон = победа.
Цель — средний матч около 20 минут.

Автор — пользователь GitHub `tuko474`, общается по-русски. Тестирует на Android, Mac/iOS нет.

## Стек и сборка

- TypeScript, Canvas 2D, без игровых движков. Vite для сборки, Capacitor для Android. Никаких npm-зависимостей в игре.
- Симуляция (`src/sim`) полностью отделена от отрисовки — её можно гонять без экрана (`tools/simtest.ts`).
- Быстрая проверка без npm: `npx tsc -p tsconfig.single.json && python3 tools/bundle.py` → `dist-single/index.html`
  (порядок файлов в `tools/bundle.py` → ORDER; новый модуль нужно туда добавить; имена верхнего уровня в разных
  модулях не должны совпадать — бандл склеивает всё в одну область видимости).
- Балансные прогоны: `npx tsc -p tsconfig.test.json && node .simtest/tools/simtest.js 20 [rush] [hard]`
  (бот против бота; `rush` — агрессивный бот против обычного, `hard` — у второго бота сложность «Сложный»).
  Если node ругается `exports is not defined` — один раз `echo '{"type":"commonjs"}' > .simtest/package.json`.
- Адрес `#debug` в конце страницы даёт в консоли `__game()`, `__renderer()`, `__online`, `__castle` — для автотестов.
- **Иконка и заставка** (`assets/`) рисуются скриптом `tools/make_icon.py` той же функцией замка, что трон в бою
  (`drawCastleFigure` в `src/render/art.ts`). Поменял замок → `npx tsc -p tsconfig.single.json && python3 tools/bundle.py && python3 tools/make_icon.py`
  (нужен playwright с chromium). Передний слой иконки держим в центре: Android обрезает края маской.

### Подпись APK (важно!)

Все сборки подписаны ОДНИМ постоянным ключом, иначе Android не ставит обновление поверх («конфликт пакетов»)
и игрок теряет прогресс. Ключ лежит в репозитории зашифрованным: `tools/android/arena.keystore.enc`.
Пароль — в секрете репозитория `KEYSTORE_PASS` (Settings → Secrets → Actions). Резервная копия ключа и пароль — у автора.
Формат ключа: PKCS12, alias `androiddebugkey`, пароли хранилища/ключа `android` (так требует debug-сборка Gradle),
DN `CN=Arena of Defense, O=tuko474, C=RU`, SHA256 `B2:31:EB:82:...:A4:39`.
Проверить подпись APK: `keytool -printcert -jarfile file.apk` → Owner должен быть `CN=Arena of Defense`.
appId пока `com.trilinii.game` — сменить ДО первой публикации в Google Play (потом нельзя).

## Сеть и онлайн

История: PeerJS не работал из сети автора → перешли на публичные MQTT-брокеры (`src/mqtt.ts`, свой клиент) →
в бою мобильная сеть в России душила поток (~45 КБ/с снимков состояния) → переделали бой на обмен только командами →
затем подняли свой сервер в Москве. Сейчас пинг 70–100 мс, без зависаний.

- **Сетевой бой (`src/main.ts`, блок «сетевой бой»)**: оба телефона считают ОДИНАКОВЫЙ бой (общее зерно случайности,
  `Game.rand()` — mulberry32; в симуляции нельзя использовать `Math.random`!). Хост ведёт бой без ожиданий и раз в 0,25 с
  шлёт журнал ходов (ход = 6 тиков = 0,2 с; какие команды выполнены в начале хода). Гость идёт по журналу с подстраиваемым
  запасом (`buffer`, 1–10 ходов). Команды гостя нумеруются и повторяются до подтверждения. Каждые 25 ходов гость сверяет
  `Game.hash()`; при расхождении хост шлёт полный снимок (`snapshot()/applySnapshot()`), применяя его и к себе.
  Любое новое состояние симуляции нужно добавить в `snapshot()/applySnapshot()` и желательно в `hash()`.
- **Сервер (`server/server.mjs`)**: Node 22, без зависимостей (свой WebSocket, встроенный `node:sqlite`).
  Аккаунты (имя + токен; пароль по желанию для входа с другого телефона), прогресс (кристаллы, открытые герои),
  рейтинг Elo (старт 1000, K=32), подбор соперника (окно рейтинга расширяется со временем), комнаты по коду для друзей,
  пересылка боя (`relay`), возврат в матч после обрыва (45 с, иначе поражение ушедшему), итог боя подтверждают оба.
  База: `/var/lib/arena/arena.db` на сервере. Перед сервером — Caddy (https/wss, сертификат сам, домен через sslip.io).
- **Установка/обновление сервера**: зайти `ssh root@31.31.192.98` и выполнить
  `curl -fsSL https://raw.githubusercontent.com/tuko474/tri-linii/main/server/install.sh | bash` — скрипт сам подтянет
  свежий код из GitHub и перезапустит службу `arena`; база сохраняется. Логи: `journalctl -u arena -f`.
- **Клиент сервера**: `src/online.ts` (класс `Online`: переподключение, вход, события, канал матча с тем же интерфейсом `Link`,
  что у MQTT/PeerJS). Если сервер недоступен — игра против бота работает, «Игра с другом» падает на MQTT.
- Локальная проверка онлайна: `DB=/tmp/test.db PORT=8080 node --no-warnings server/server.mjs`, в браузере
  `localStorage.setItem('tl-server','ws://127.0.0.1:8080')`.

## Игровые системы (кратко)

- **Карта** (`src/sim/map.ts`): WORLD 5400×3000, троны в углах, река по диагонали, логова Лорда (t=0.31) и Черепахи (t=0.69),
  стражи у входов в логова (захват = обзор логова), до 10 лесных лагерей на половину. Бараки у начала каждой линии
  (`barracksPos`, крипы выходят оттуда), алтарь за троном (`ALTAR_POS`).
- **Туман войны**: сетка видимости 50 единиц; внутрь логова видно только со своим стражем или своим отрядом там.
- **Герои** (`src/data/heroes.ts`): 30 героев, 6 рас по 5, по 3 стартовых в каждой расе (18 открыты сразу, 12 за кристаллы).
  Уровни растут сами от опыта (крипы на своей линии, лес, стражи, боссы, убийства) — покупки уровней нет (решение автора).
- **Расы** (`src/data/races.ts`): нежить, стихии, дикие, королевство, горные, тени. Бонусы при 2 и 4 героях.
  Сфера Лорда: +1 к расе случайного героя твоей команды (чем больше героев расы — тем вероятнее), пока Лорд не возродится.
- **Походы**: героев можно отправить в лес / к стражу / Черепахе / Лорду и вернуть (↩, «Все на линию»).
  Если все живые герои линии ушли — крипы врага займут позицию («брошенная позиция»).
- **Переход** (вместо общей «Подмоги», убрана 3 окт 2026): у каждого героя в нижней панели кнопка-подпись линии («Центр ⇄»).
  Герой мгновенно идёт на выбранную линию на 25 с и сам возвращается (`moveHero`, `sendHome` — вернуть раньше бесплатно).
  Цена 80 + 5/мин за героя, перезарядка 60 с у каждого своя (`h.moveCd`, `BAL.move`). Бот переводит до 3 героев на продавленную линию.
- **Траты золота** (решение автора — выкупа героев НЕТ):
  - Барак линии: сила крипов (+20%/ур., лимит по времени: +1 уровень каждые 75 с) и уровень барака 1–3 (доп. крипы, 450/900/1500).
  - Алтарь: ауры только для героев — стойкость (−5% урона/ур.), ярость (+8% атаки/ур.), мана (+20% реген/ур.), 5 ур. по 300/600/1000/1500/2200.
  - Трон: пушка (5 ур.) и глиф (200 золота, 5 с неуязвимости героев на линиях И самого трона, перезарядка 120 с).
    Бот (normal/hard) жмёт глиф и когда трон бьют, а прочности меньше 30%.
- **Трон** нарисован замком (вид спереди, как бараки): кэш-картинки по стороне и разрушениям; ниже 66% прочности — трещины и дым,
  ниже 33% — выбитые камни и огонь; под атакой мигает и дрожит. Кольцо прочности лежит на земле и убывает к переду.
  Нажатие на трон ловится по прямоугольнику замка (`buildingAt`). Под глифом над замком золотой купол.
- **Нейтралы нарисованы** (`drawBeastFigure` в `art.ts`): лагеря — волки / кабаны / пауки (по `id % 3`), Черепаха, Лорд-демон
  с крыльями. Кэш-картинки в `beastSprites`, лёгкое «дыхание». Боссы в бою не мигают — иначе видно бой сквозь туман.
- **Против раша**: глубже позиция — больше брони (`depthArmor`) и урона (`depthAtk`) у героев; трон стреляет по крипам.
- **Бот** (`src/sim/bot.ts`): уровни easy/normal/hard (hard: +20% дохода, чаще лес и боссы, раньше оборона, подмога, глиф).
- **Драфт**: порядок 1-2-2-2-2-1, 25 с на выбор, только открытые герои (если открытых свободных нет — любой как пробный).
- **Мета**: кристаллы (старт 300; победа 150, поражение 60, +20 за Лорда), открытие героев за кристаллы.
